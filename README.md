# SwAT Presentations

Slides made with [Typst](https://typst.app/). They're easy to share and view on GitHub, and they look clean.

## Adding a presentation

Make your own folder (e.g. `leader_intro/`) and keep all of your files in it. Add a short
`README.md` saying what the talk is and when it's used. Sticking to your own folder means
you won't get merge conflicts with anyone else.

## Getting started

The easiest setup is the **Tinymist Typst** extension for VS Code, plus a template from
[typst.app](https://typst.app/).

Look through the existing `*.typ` files before you start. They have predefined styling
that can speed things up.
